10 Omni Skills Production
Google Omni Skills 3 files

AI skills to use with Google Omni for automated ad generation. These are pre-built prompt systems that generate complete ad scripts + clip-by-clip Omni prompts from a single product description.

  • Whiteboard Skill — 05-skills/omni-whiteboard-skill.zip — Generates whiteboard-style animated ads
  • VOX Style Skill — 05-skills/vox-style-skill.md — Full prompt system for Vox paper-collage animation ads (10s clips, DR copywriting built in)
  • Chalkboard Skill — 05-skills/omni-chalkboard-skill.zip — Chalkboard-style animated ads
What are these skills? Each skill is a detailed system prompt that turns Claude (or ChatGPT) into a specialized ad-creation assistant. You give it your product + offer, and it outputs a complete voiceover script plus copy-paste-ready Google Omni prompts for each 10-second clip. See the tutorial below for how to use them with Claude Code.
→ How to Use Skills with Claude Code

Quick Setup (5 minutes)

Claude Code is a terminal-based AI assistant. You can load "skills" (specialized prompts) that turn it into a domain expert. Here's how to use the Omni skills from this course.

1

Install Claude Code

Open your terminal and run:

npm install -g @anthropic-ai/claude-code

Requires Node.js 18+. You'll need an Anthropic API key or a Claude Max subscription.

2

Create a skills folder

Navigate to any project folder and create a .claude/skills/ directory:

mkdir -p .claude/skills
3

Add a skill file

Copy vox-style-skill.md into .claude/skills/. For the .zip skills, unzip them first — they contain similar .md prompt files.

cp 05-skills/vox-style-skill.md .claude/skills/vox-style.md
4

Launch Claude Code and use the skill

Start Claude Code in the same folder, then invoke the skill:

claude # Once inside, type: /vox-style

Claude will load the skill and ask you 3 intake questions (product image, clip chaining, simple vs complex mode). Then give it your product + offer and it generates everything.

5

Copy prompts into Google Omni

Claude outputs numbered clips (CLIP 1, CLIP 2, ...) with copy-paste-ready prompts. Paste each clip's prompt into Google Omni, generate the 10s video, then move to the next clip. Stitch them together in CapCut or your editor of choice.

Alternative (no Claude Code): You can also paste the entire content of vox-style-skill.md as a system prompt in ChatGPT or the Claude web app. It works the same way — Claude Code just makes it faster to invoke repeatedly.
